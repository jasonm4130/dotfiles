## Plan adjustments / deviations worth remembering

1. **`.chezmoiignore` had to be created early** with repo-meta exclusions (LICENSE, README, docs/, bootstrap.sh). Without these, chezmoi would deploy them to `~/`. The `.claude/` allowlist was appended on top in Task 10.
2. **`.gitignore_global` didn't exist** on the seed machine — `touch` created it as empty (chezmoi auto-prefixed `empty_` so it's tracked).
3. **Zed LMDB (`prompts-library-db.0.mdb`)** was pulled in by `chezmoi add ~/.config/zed/prompts/`. Removed from source dir; Zed's user prompts dir is currently empty.
4. **Task 13 was scoped to NEW packages only** (starship/mise/gitleaks/claude-code/font-monaspice-nerd-font) — full `brew bundle install` would have triggered ~25 upgrades including pyenv (which we're removing) and large casks (inkscape, qgis, llvm). Full bundle runs on fresh-machine bootstrap, not seed.
5. **Cask name fix**: `font-monaspace-nerd-font` is a deprecated alias for the canonical `font-monaspice-nerd-font`. packages.yaml updated.
6. **`render.sh` test run overwrote `~/.claude/CLAUDE.md`** (cleaner format, same semantics). Tracked source `private_dot_claude/CLAUDE.md` then went stale, and Task 32 was front-loaded to un-track it cleanly.
7. **Task 32 + 33 + 34 done out of order** at user request ("CLAUDE.md safe state + gitleaks first") — addressed the runtime gotcha and added secret-scanning before any further work.
8. **gitleaks pre-commit hook**: the plan called for `gitleaks protect --staged` (deprecated) AND `gitleaks git --pre-commit` (broken on this v8.30.1 Mac — reports "0 bytes scanned"). The working pattern is `git diff --cached -U0 | gitleaks stdin`. The live hook uses this; the plan doc still has the older command for Task 34 and should be updated when next touched.
9. **chezmoi apply scoped to files only** (`--include=files`) for any Phase 5+ work — prevents the bootstrap scripts (`run_once_*`, `run_onchange_*`) from running prematurely on the seed machine. They'll run on the VM test (Task 36).
10. **Time Machine sidebar**: configured Unraid SMB-based TM share (out of scope for original plan but invaluable). 2TB cap, `valid users = jason`.
